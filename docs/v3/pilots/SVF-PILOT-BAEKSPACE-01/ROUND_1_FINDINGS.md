## 3. What SVF Round 1 changed

### Change 1 — B moved from “preferred implementation plan” back to “testable product hypothesis”

The Studio concept remains coherent.

But current evidence does not justify treating conceptual coherence as market validation.

### Change 2 — A strengthened

External validation of the current Core directly addresses a major evidence gap:

> technical maturity is high while external behavioral evidence remains weak.

### Change 3 — C weakened

Further core expansion currently resolves fewer of the highest-priority Unknowns than user validation.

This is provisional and can reverse if real users repeatedly encounter the same missing blocker.

### Change 4 — the baseline action set was incomplete

Round 1 introduced:

> **D — validate current Core externally while testing the Studio job through a manual/disposable prototype before full Studio software investment.**

D is not yet selected.

Its purpose is to test whether both major hypotheses can be discriminated with less build.

### Change 5 — the problem type changed

The current Decision Episode is not primarily:

- optimization;
- forecasting;
- system dynamics;
- deep uncertainty modeling.

It is primarily:

> **an information-acquisition problem.**

The key question is:

> What is the smallest evidence-gathering action that could materially change the A/B/C/D decision?

---

## 4. First provisional SVF utility signal

Round 1 produced at least one non-cosmetic difference from the baseline:

> **It exposed a previously unregistered action class (D) and converted Studio from an implementation-default into a hypothesis that must earn investment.**

This counts as a **provisional method-value signal**.

It does **not** yet prove SVF is valuable because:

- a good ordinary product strategist might reach the same conclusion;
- a one-page checklist might produce D with less overhead;
- no external behavior has been observed;
- no intervention has changed yet.

Therefore SVF's current method status remains:

> **PROMISING, NOT VALIDATED**
