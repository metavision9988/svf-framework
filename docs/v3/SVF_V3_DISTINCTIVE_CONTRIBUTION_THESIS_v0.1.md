# SVF v3.0 Distinctive Contribution Thesis v0.1

**Stage:** 2 — contribution thesis  
**Status:** Research hypothesis, not a validated claim  
**Date:** 2026-09-18

## 1. The problem this thesis addresses

After removing unsupported universal equations, a legitimate question remains:

> If system dynamics, causal inference, control theory, decision analysis, DMDU, DAPP, and measurement science already exist, why should SVF exist?

SVF v3 should have an answer stronger than “it combines useful ideas.”

## 2. Working thesis

**SVF's candidate distinctive contribution is not a superior mathematical estimator. It is a protocol that keeps the full navigation chain coherent across heterogeneous methods.**

The chain is:

```text
EVIDENCE
  ↓
CURRENT STATE
  ↓
OBSERVED TRAJECTORY
  ↓
FIELD / CONSTRAINTS
  ↓
CAUSAL & COMPETING HYPOTHESES
  ↓
METHOD SELECTION
  ↓
CANDIDATE INTERVENTIONS
  ↓
SCENARIO / ROBUSTNESS TEST
  ↓
DECISION
  ↓
SIGNPOSTS / TRIGGERS
  ↓
OBSERVED CONSEQUENCE
  ↓
UPDATE / ADAPT
```

Many specialist methods are excellent at one or more links. SVF seeks to make the **interfaces between the links** explicit and inspectable.

## 3. Minimum unique bundle

An analysis should not be called “SVF v3” merely because it uses State/Field terminology.

The minimum bundle requires:

1. State ≠ Trajectory ≠ Goal ≠ Action;
2. internal Constraint ≠ external Field;
3. claim type attached to material conclusions;
4. source/evidence provenance;
5. Unknowns preserved explicitly;
6. at least one competing hypothesis where causality is material;
7. specialist-method routing when the question exceeds SVF Core competence;
8. intervention assumptions exposed;
9. adaptation/signpost condition for nontrivial dynamic decisions;
10. visual/data representation consistent with the protocol.

Without these, the output is generic strategic analysis, not v3.

## 4. Candidate contribution layers

### Layer A — Semantic discipline

Prevents category errors such as:

- intention mistaken for trajectory;
- low score mistaken for binding constraint;
- correlation mistaken for intervention evidence;
- external Field mistaken for actor-controlled Action;
- unknown mistaken for zero.

### Layer B — Epistemic discipline

Forces analysts and AI to show:

- what is observed;
- what is calculated;
- what is inferred;
- what remains a hypothesis;
- what is conditional scenario;
- what is unknown.

### Layer C — Methodological interoperability

Allows a case to move from:

`SVF framing → causal analysis → RDM → pathway planning`

without losing the semantic identity and evidence trail of the original claims.

### Layer D — Adaptive memory

Preserves a decision as a time-indexed object rather than replacing yesterday's reasoning with today's hindsight.

### Layer E — Dual human/machine protocol

The same method can be represented as:

- questions/interview;
- tables/canvases;
- visual graphs;
- typed machine objects;
- evidence/provenance links.

This is essential for a future SVF service and for SKEC integration.

## 5. Why this might matter in an AI environment

Generic LLM analysis can produce fluent explanations but may silently:

- fill missing variables;
- merge fact and interpretation;
- choose one causal story;
- invent precision;
- forget the assumptions behind earlier advice.

SVF v3 could function as a reasoning contract around an LLM:

`LLM expression/research capability + SVF epistemic/navigation protocol`

The empirical question is whether this produces more reliable decision work than prompting an LLM without the protocol.

## 6. Falsifiable value hypothesis

SVF v3 is valuable only if comparative testing shows meaningful gains relative to simpler alternatives.

Candidate hypotheses:

### H1 — Omission
SVF users identify more material variable classes and fewer category omissions than unaided analysis / SWOT / generic LLM.

### H2 — Epistemic clarity
SVF outputs contain fewer unsupported factual or causal claims.

### H3 — Uncertainty visibility
SVF users identify more decision-relevant unknowns and express uncertainty more appropriately.

### H4 — Intervention quality
SVF produces interventions with more explicit mechanisms, assumptions, test criteria, and stop/pivot conditions.

### H5 — Traceability
Independent reviewers can more easily reconstruct why a conclusion or decision was reached.

### H6 — Reassessment quality
When new evidence arrives, SVF users can identify which claims and decisions should change with less hindsight rewriting.

### H7 — Inter-rater protocol consistency
Different analysts using SVF encode the same case more consistently than analysts using unstructured prose.

If these effects do not materialize—or if they are outweighed by complexity/time cost—the v3 methodology should be simplified or its scope reduced.

## 7. Benchmark set

Future comparative evaluation SHOULD include:

- unstructured human analysis;
- generic LLM analysis;
- SWOT;
- a simple checklist;
- domain expert analysis;
- SVF Core only;
- SVF + relevant specialist method.

SVF should not choose a weak straw-man baseline.

## 8. Product thesis

The service opportunity is not primarily:

> “AI gives you an SVF score.”

A more defensible product thesis is:

> **“Turn messy situations into an inspectable decision map; show what is known, what is changing, what might cause it, what should be tested, and what signal should change the plan.”**

Possible product layers:

- **Lens** — guided framing and Navigation Map;
- **Navigator** — evidence, hypotheses, intervention tests, signposts;
- **Workbench** — specialist-method adapters and team collaboration;
- **Engine/SDK** — typed protocol, Domain Packs, adapters;
- **SVF + SKEC** — provenance/change-aware continuous navigation.

## 9. Research risk

The largest risk is that the protocol becomes too elaborate for normal use.

Therefore v3 must preserve two modes:

### Quick Lens
A small number of questions and one Navigation Map.

### Deep Workbench
Full Evidence Ledger, Method Router, specialist analyses, pathways, and decision history.

The Quick Lens is not allowed to fabricate the precision of the Deep Workbench.

## 10. Current contribution statement — safe wording

Until validation is completed, the project may say:

> **SVF v3 proposes an evidence-grounded navigation protocol that integrates situation framing, claim discipline, specialist-method routing, visual representation, and adaptive decision tracking through one common semantic contract.**

It should not yet say:

- SVF is scientifically superior;
- SVF predicts better;
- SVF finds optimal strategies;
- SVF is the first framework to use feedback, fields, pathways, or uncertainty;
- SVF's integration is unique without a literature review sufficient to support priority claims.

## 11. Stage-2 research implication

The next work should transform this thesis into:

1. a visual Method Stack;
2. explicit Router decision rules;
3. a benchmark case set;
4. one simple and one complex worked example;
5. a literature map identifying inherited vs adapted vs genuinely novel artifacts.
