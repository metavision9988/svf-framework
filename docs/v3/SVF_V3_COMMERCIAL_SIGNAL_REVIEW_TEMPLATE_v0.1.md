## 12. Willingness-to-pay discipline

Internal pilots SHALL NOT answer:

> “How much would customers pay?”

unless external evidence exists.

Instead record:

- What budget category might plausibly fund this?
- What comparable service/tool is already purchased?
- What external validation is still required?

Real WTP evidence begins with behavior:

- time/data commitment;
- external pilot;
- paid workshop;
- paid advisory;
- paid software pilot;
- repeat purchase.

---

## 13. Commercial disposition

Choose one:

- **C-GO** — meaningful external commitment exists; proceed to next commercial experiment.
- **C-DISCOVER** — problem/value plausible; external discovery required.
- **C-NARROW** — value exists only for a narrower buyer/use case.
- **C-SERVICE** — consulting/service value appears stronger than software value.
- **C-HOLD** — insufficient signal.
- **C-STOP** — simpler alternatives dominate / no meaningful pain.
